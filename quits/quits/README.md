# Quits — see the home you both pay for

A web app for US couples who both earn money and share household costs. Once a month, each partner uploads a card statement (CSV). Quits sorts every line into **Home** or **Mine**, shows who paid for groceries, school, bills and the car, keeps personal spending private, and ends the month with one fair transfer.

Business Cup 2.0, Track 1: Money. Web, B2C, US adults 25–45.

## Как запустить (30 секунд)

**Вариант 1: просто открыть.** Распакуйте архив и дважды кликните `index.html`. Всё работает в браузере без установки и без сервера.

**Вариант 2: локальный сервер** (если браузер блокирует файл):
```
cd quits
python3 -m http.server 8000
```
Затем откройте http://localhost:8000

или `npm start` (нужен Node.js, запускает `npx serve`).

**Вариант 3: ссылка для жюри.** Перетащите папку на https://app.netlify.com/drop: через минуту будет публичная ссылка. Подойдут также Vercel или GitHub Pages: это обычный статический сайт.

## Демо за 2 минуты

1. **Try the demo couple**: Jess и Alex, Остин, ноябрь 2026.
2. **Home**: дом с полками. Каждая полка — категория дома, каждая коробка — $100. Зелёные коробки оплатила Jess, жёлтые — Alex. Фундамент внизу показывает, сколько бюджета дома ушло.
3. Переключите **Viewing as → Jess**: появляется «Jess's room» с личными тратами. Их видит только она. В режиме **Together** личного нет.
4. **Statements**: строки из выписки, умная сортировка, кнопки Home/Mine. Amazon подсвечен как «проверь». Строки Alex у Jess только для чтения.
5. **Runway & pause**: $520 свободно на 16 дней, предупреждение «запас тонкий», счета впереди. Пауза 24 часа: робот-пылесос, влияние на запас, голос партнёра, кнопка «Skip ahead 24h (demo)».
6. **Settle up**: Alex → Jess $540 при 50/50; переключите на **By income**, станет $727. Затем Mark as settled.
7. **Money moves**: 8 действий по финансовой грамотности, посчитанных на данных пары.
8. **Ask Quits**: спросите коуча «как не уйти в ноль?», запишите стороны Jess и Alex в Talk it out, нажмите Find common ground.

Свои выписки: файлы-примеры лежат в `samples/` (Chase и Amex форматы). Нажмите Upload и выберите файл.

## ИИ (OpenAI)

Без ключа всё работает на встроенной логике: правила сортировки, встроенный коуч и шаблоны. С ключом включаются:

- **Автосортировка.** После загрузки выписки ИИ сам раскладывает неясные строки (Amazon, Target…) по «Home/Mine» и категориям. Кнопка «Sort my unconfirmed lines with AI» пересортировывает все неподтверждённые строки. Пользователь только подтверждает.
- **Ask Quits → Quits Coach.** Чат-помощник по финансовой грамотности. Отвечает на ваших цифрах (запас, расчёт, бюджет), по-английски или по-русски. Видит траты на дом и только свои личные строки, личные строки партнёра никогда.
- **Ask Quits → Talk it out.** Посредник: каждый партнёр приватно пишет свою сторону, ИИ выдаёт общую цель, потребности обоих, 3 шага на месяц и первую фразу для каждого. Если в тексте есть признаки угроз или контроля над деньгами, показывается горячая линия (1-800-799-7233).
- **Ask Quits → Say it kindly.** Переписывает резкое сообщение в спокойное «я-сообщение» с вопросом.
- **Home → Quits Coach suggests.** 3 персональных совета на месяц.

### Как включить на своём ноутбуке (для демо)
1. Получите ключ: https://platform.openai.com/api-keys (нужен баланс на аккаунте).
2. В приложении нажмите **AI offline** вверху или **Setup** внизу, вставьте ключ, Save.
3. Модель по умолчанию `gpt-5-mini`. Если её нет на вашем аккаунте, приложение само попробует `gpt-4.1-mini`, затем `gpt-4o-mini`. Можно вписать свою модель.

Ключ хранится только в этом браузере и уходит только на api.openai.com. **Не вписывайте ключ в код** и не отправляйте его вместе с архивом.

### Как включить на публичной ссылке (ключ на сервере, не утекает)
Ключ хранится только в настройках Vercel. В коде, в GitHub и в браузере посетителей его нет. Сайт обращается к своей функции `/api/ai` (файл `api/ai.js`), и только она ходит в OpenAI.

1. **GitHub.** Создайте репозиторий (можно Private) → «uploading an existing file» → перетащите всё **содержимое** папки `quits` → Commit.
2. **Vercel.** vercel.com → войдите через GitHub → Add New → Project → Import ваш репозиторий.
3. На экране Configure откройте **Environment Variables**: Name `OPENAI_API_KEY`, Value — ваш ключ → Add → **Deploy**.
4. Через минуту появится ссылка `https://….vercel.app`. На ней вверху должно быть «AI on».

Защита в функции:
- запросы принимаются только с вашего сайта: чужие сайты и curl получают 403;
- 20 запросов к ИИ за 10 минут с одного адреса и не больше 300 в час;
- ограничен размер запроса и разрешены только модели gpt-5-mini, gpt-4.1-mini и gpt-4o-mini;
- ошибки OpenAI отдаются наружу без подробностей.

Главная страховка: в OpenAI → Settings → Limits поставьте месячный лимит ($5–10). Сделайте для сайта отдельный ключ и удалите его после хакатона.

Если ключ попал в GitHub или в чат, сразу удалите его в OpenAI → API keys и создайте новый.

Альтернатива: Netlify через Git (функция `netlify/functions/ai.mjs`, переменная `OPENAI_API_KEY`). Netlify Drop функции не запускает.

## Технически

- Чистый HTML, CSS и JavaScript, без сборки и зависимостей. Файлы: `index.html`, `styles.css`, `app.js`. Серверные функции для ИИ: `netlify/functions/ai.mjs`, `api/ai.js` (необязательны).
- Данные хранятся только в браузере (localStorage). Ничего не отправляется на сервер.
- Шрифты подгружаются с Google Fonts; без интернета будут системные шрифты.
- Сброс: внизу Setup → Reset everything.
